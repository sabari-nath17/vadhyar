Before you start

A few clear answers.

Does Vadhyar write the fix for me?

No. In the learning workflow, the coach explains and gives progressive hints. You inspect and edit the code yourself in VS Code.

Does this website run the extension?

The walkthrough here is an illustration. The extension uses real project source, OpenAI API requests for coaching, and executed checks in its prepared exercise. The website makes no AI calls.

Can I use it with any repository?

The 0.1.0 installer supports the included milestone learning project. Broader Project Guide work is in development and is not included in this installer.

Where does my data go?

Code checkpoints and recorded activity stay in workspace-scoped VS Code storage. API credentials use VS Code SecretStorage. Coaching sends the context shown in your sharing preview to OpenAI after your approval.

Do I need a ChatGPT subscription?

You need separate OpenAI API access for explanations and hints. A ChatGPT subscription does not supply the API key. Local source inspection, predictions and prepared checks do not need an API key.

What has been tested?

The release has development checks and recorded native editor acceptance. It has not established learning gains. See the GitHub release notes for this package’s checks and remaining platform limits.
