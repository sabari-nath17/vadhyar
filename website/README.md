# Vadhyar landing page

Static HTML, CSS and JavaScript. No framework, backend, analytics or runtime font requests. The author-supplied wordmark is unchanged; the Guide is an original hand-built SVG. Bundled Inter and Playfair fonts retain OFL notices. DESIGN.md preserves the supplied v2 brief; marketing adaptation uses its palette, shapes, typography and honesty rules without asserting the proposed extension screens have shipped.

Check: `node website/check.mjs`; local preview: `python3 -m http.server 4183 --directory website --bind 127.0.0.1`. Deploy only this folder to the Vercel project. The primary link downloads the versioned GitHub VSIX. The interactive walkthrough is labelled illustrative and sends no network/API requests.

Release snapshot is isolated from the active working tree; installer scope and exact prerequisites are in ../docs/installation.md.
