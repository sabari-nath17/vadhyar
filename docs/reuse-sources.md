# Reuse decisions and evidence

Reviewed 10 October 2026. These are source/documentation observations, not local runtime verification. Recheck the exact chosen revision and applicable notices before copying or distributing code. No third-party implementation was imported during repository setup.

| Source | Evidence inspected | Decision |
|---|---|---|
| [Graphify](https://github.com/Graphify-Labs/graphify), [package metadata](https://github.com/Graphify-Labs/graphify/blob/v8/pyproject.toml) | Earlier research inspected code-only CLI extraction, graph schema/version metadata and Python requirements; candidate release 0.9.84. | Use as a pinned external CLI once the integration gate confirms compatibility. Retain applicable notices. |
| [CodeTour](https://github.com/microsoft/codetour), [schema](https://raw.githubusercontent.com/microsoft/codetour/main/schema.json), [MIT license](https://raw.githubusercontent.com/microsoft/codetour/main/LICENSE.txt) | README describes ordered editor walkthroughs. Schema has source locations and selections, but also commands and a JavaScript condition. | Reuse the navigation concept and safe data shape. No complete extension dependency. Validate ranges; prohibit executable fields. Retain copyright/license for any later copied material. |
| [Tour de Code AI README](https://raw.githubusercontent.com/Tour-de-Code-AI/Tour-de-Code-AI/main/README.md) | README describes repository context and LLM-generated tours. Main GitHub page failed during this pass; raw README was accessible. Generator implementation was not re-audited. | Reference only. Do not repeat marketing performance/privacy claims as verified facts. |
| [Cline](https://github.com/cline/cline) | Current repository describes a broad coding agent and checkpoints. Its narrow comparison implementation was described in user-supplied research but not re-audited in this pass. | Reference only. Native snapshots/diff avoid transplanting a larger agent runtime. |
| [OpenSpec](https://github.com/Fission-AI/OpenSpec) | Repository presents a spec-driven workflow. | Borrow concise requirement/scenario conventions. No runtime dependency or claim of full format compatibility. |
| [Vitest reporters](https://vitest.dev/guide/reporters) | Implementation reference to consult for the pinned version's machine-readable report format. | Direct dependency; validate expected case coverage and process status. Reporter docs were not newly opened in this pass. |
| [Promptfoo](https://github.com/promptfoo/promptfoo) | Repository documents evaluation/assertion tooling. | Development-only evaluation after the real learning loop works. Human review remains necessary for teaching quality. |
| [VS Code webviews](https://code.visualstudio.com/api/extension-guides/webview), [API](https://code.visualstudio.com/api/references/vscode-api), [Workspace Trust](https://code.visualstudio.com/api/extension-guides/workspace-trust) | Earlier planning consulted official documentation for editor/host boundaries, credential storage and trusted code execution. | Prefer native navigation, diff and storage. Trust is not process isolation. |
| [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [model candidate](https://developers.openai.com/api/docs/models/gpt-6-astra) | Earlier planning consulted official docs. | Recheck current model support and account access before implementation. Schema adherence does not prove explanation accuracy. |

StrykerJS remains deferred. Open Vibe, PRIMM-AI+, Canopy, Continue and Serena are not implementation dependencies in this plan. The supplied research's detailed maintenance/license claims for these projects were not independently refreshed here; do not copy their code on that basis.

For each actual dependency/adaptation record: project, exact package version or commit, files copied if any, license/notice location, local modifications, and the integration evidence. Keep recommendations separate from working integrations.
