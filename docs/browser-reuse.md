# Browser source reuse

The browser uses selected Learn Claude Code components, a bounded PocketFlow workflow port and the published React Flow package. These post-event adaptations inspect learner-selected captured source. They do not execute the project, send source to a model or advance a learning gate.

## Current behavior

In Project, select saved JavaScript/TypeScript and request source concepts. The viewer, ordered text path, manual controls and inert map navigate exact captured anchors. At most five graph concepts are selected per excerpt; complete/partial declaration catalogues and selected multi-range reading are documented in [source reading](source-reading.md). Other readable languages retain explicit unsupported-extraction states.

The protected walkthrough endpoint binds project/file/hash/range and rejects stale source. The [knowledge backend](backend-knowledge.md) extends the same deterministic extraction to explicit selected ranges and static module links. Neither endpoint gives the browser arbitrary path, command, provider or editing authority.

The installed TypeScript compiler analyzes captured text in memory without reading project configuration, imports or library source. Static calls/type links require supported complete captures; relative module links consult selected paths only. Unsupported, dynamic, ambiguous, omitted and runtime relationships remain unknown. Order is a proposal, not a correctness or learning grade.
