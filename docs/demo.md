# NovaDesk demo rehearsal

Use a fresh prepared folder and the installed macOS-arm64 VSIX described in [release setup](release.md). Keep the source and Vadhyar panel beside each other. Use a readable wide panel and show the actual code/diff; Settings and technical identities are expandable.

1. **Rule:** confirm that only the owning client may approve. Explain that the seed deliberately checks only role; actors are simulated and this is not authentication. Save a source snapshot.
2. **Source:** refresh real Graphify relationships, confirm mapping and open the function in the native editor. With securely stored API access, review the exact filenames/payload and request an explanation. If API access is absent, state that coaching is unavailable and continue through **Predict**; do not present an old response as live.
3. **Prediction:** choose Allow or Deny, write a reason and save before running. The other client is allowed by the seed, so the actual requirement check visibly fails even if the prediction was correct.
4. **Edit:** optionally review/request progressive hints. The coach never writes source. Edit and save yourself, refresh, inspect the native captured-before/saved-after diff, then run all three fixed cases. Required results: owning client allow; different client deny; freelancer deny. Deny-all fails the owner case.
5. **Transfer:** start the archived challenge. Confirm its separate requirement, save another prediction, inspect the archived failure, extend your own saved decision and rerun all four checks. Active owner still succeeds; archived owner, other client and freelancer are denied.
6. **Evidence:** save a reflection, inspect the timeline and optionally export the inert Markdown handover. Show current versus historical identities and actual hint count. Passing checks demonstrates these cases, not authorship, understanding or mastery.
7. **Resume:** close/reopen the panel or restart only this demo window. Saved records/stage resume; API/extraction/checks do not run automatically. An edited source or requirement makes old evidence historical.

For a repeat, prepare another new folder with `demo:prepare`. **Clear NovaDesk session** is a separately confirmed memory operation; it preserves source, credentials and Project Guide records, so it does not restore seeded source. Never clear the active learner's folder for a rehearsal.
