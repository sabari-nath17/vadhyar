# Feature visibility and scope

The interface should first answer: **What can Vadhyar help me do with my project?** The own-project entry is now prominent, followed by a clearly labelled prepared practice path. Static labels describe existing capabilities; all project names, source, outputs, counts and verdicts still come from state.

| User goal | Visible entrypoint | Existing action boundary and limit |
|---|---|---|
| Keep my idea or PRD | Project Guide → Your idea | Add/import/confirm/change an intention; earlier revisions retained. Import is not automatic proof of coverage. |
| See what AI changed | Project Guide → What changed | Snapshot, file selection, native diff and optional reviewed grouping. Tracking starts when enabled; prior authorship is unknown. |
| Understand why code matters | Project Guide → How it works | Reviewed explanation: purpose, logic, consequence and source links. Actual model output, not generated placeholder copy. |
| Get help with the next prompt | Project Guide → How it works → Review a build plan and prompt | Review context, receive a proposed plan, inspect and copy its prompt. Copying does not run code or send it to a coding agent. |
| Debug and make a change myself | Guided practice → Your guess / What happened / Try a change | Saved prediction, real prepared counterexample, source links, progressive hints and human editing. Prepared ownership/archived tasks; arbitrary-domain exercise generation is not implemented. |
| Check saved code | Project Guide → Check it; guided practice → Check it | Project mode selects an existing script and asks native confirmation. Practice executes pinned three/four-case checks. A script pass is not whole-PRD verification or proof of learning. |
| Return to history and proof | Project Guide → Saved ideas / What changed; practice → Show my proof | Existing local history, reflection/handover/export and host currentness gates. Project check output remains ephemeral. |
| Connect AI and control sharing | More options; exact sharing review | Existing masked key entry/SecretStorage and reviewed context. No automatic upload, new endpoint or invented response. |
| Capture coding requests | Project options → agent capture bridge | Explicit supported command/hook only; enabling does not intercept every editor or tool. |
| Take a break | Practice path / options → Snake | Local engine and actual game score; no learning-score connection or network calls. |

## Navigation limit

The prepared lesson and Project Guide are separate existing editor commands. The NovaDesk host has no open-project action or enabled command links. The interface therefore names **Vadhyar: Open Project Guide** rather than drawing a fake working button. A single interactive launcher requires a host change and remains outside this request.

## Planned, not advertised as available

General automatic PRD-drift auditing, alternative implementation generation, whole-repository educational checks, universal agent capture, OAuth sign-in, demo reset and recorded-response fallback. Existing experimental Project Guide is available; it is not labelled planned. Existing Graphify relationship evidence belongs to the prepared adapter and does not establish runtime behavior or a general project execution graph.

The baseline action coverage and all 23 immutable source hashes are checked after the communication changes. Browser previews demonstrate presentation, not native/live API acceptance or tested child usability.
