## Mini-PRD

Help a beginner understand an AI-built feature, make a change themselves and check it against their intention. Retain requirement → selected source → prediction → observed behavior → human edit → executed checks → follow-up. NovaDesk supplies the fully mapped prepared learning loop; Project Guide supplies explicitly selected local project context and reviewed existing npm checks. One second project proves only its tested workflow, not universal repository or runtime support.
