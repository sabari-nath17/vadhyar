# Vadhyar

<!-- impeccable:product-schema 1 -->

## Platform
web — React webview inside a local VS Code extension.

## Users
Beginners, non-developers and students using AI to build a personal project, then trying to understand and change its code.

## Product Purpose
Connect a confirmed requirement to current source, prediction, observed behavior, learner-owned edits and executed checks.

## Capabilities and Constraints
The current build supports only the prepared NovaDesk ownership scenario. Graphify provides source relationships, OpenAI supplies explanations and hints, and the trusted runner supplies outcomes. Explanations are not verification. Credentials remain in SecretStorage. Explicit requirement, mapping and context-sharing approvals remain host-owned. Source edits invalidate current advice/results. Transfer, Review and general Build Guide remain planned.

## Brand Commitments
The user's supplied Vadhyar Design System defines the Digital Manuscript identity and patient, precise voice. Preserve native editor source, bundled offline fonts, light/dark/high-contrast support and reduced motion. The supplied transparent wordmark is the only logo variant.
